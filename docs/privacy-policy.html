Site Identity

Privacy Policy

This Privacy Policy describes how the Site Identity browser extension handles user data.

← Back to Home

Data Collection

Site Identity does not collect, transmit, or store personal data on external servers. All phishing detection is performed locally within the user's browser.

Local Storage

The extension stores user preferences, such as trusted domains and temporary allow-list entries, only in the browser using Chrome's local storage.

Data Sharing

Site Identity does not send browsing history, visited URLs, page content, or personal information to any server or third party.

Analytics

The extension does not use analytics, advertising, tracking technologies, or telemetry.

Remote Processing

All detection rules are packaged within the extension and processed locally on the user's device.

Changes

This Privacy Policy may be updated from time to time to reflect changes to the extension or legal requirements.
