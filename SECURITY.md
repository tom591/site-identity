# Security Policy

## Reporting a Security Issue

If you discover a security vulnerability, detection bypass, or any other security-related issue in Site Identity, please report it responsibly.

Please do not disclose the issue publicly before it has been reviewed.

You can report security issues by opening a GitHub Issue or by contacting the maintainer directly.

Please include:

- Extension version
- Chrome version
- Description of the issue
- Steps to reproduce (if possible)
- Screenshots or additional information

Thank you for helping improve the security of Site Identity.
